Screenshots are generated from public routes and stored in /dataroom/screenshots.

- /marketplace

- /student/vor-trainer

- /dataroom/screenshots/mobile/*.png

## Generate / refresh

Run:

- Node: dataroom/scripts/capture-screenshots.mjs

Update this file if routes or filenames change.
