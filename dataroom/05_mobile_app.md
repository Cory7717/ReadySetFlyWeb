# Mobile app status

## Overview

- React Native (Expo) app for iOS and Android.
- Uses the same backend API and shared TypeScript schemas.
- Targets parity with web, excluding admin.

## Current capabilities

- Rentals browsing, booking, and payments
- Marketplace browsing and listing creation
- Profile management, verification status
- Balance and withdrawals
- Real-time messaging UI shell

## Known parity gaps (from internal analysis)

- Favorites / wishlist
- Reviews system (create and view)
- Messaging (functional, real-time)
- Pilot tools (weather, logbook, resources)
- Ownership cost calculator
- Some profile sub-screens (my listings, personal info)

## Setup note

- Requires react-native-webview install for payments.
